# Release Notes — v1.0.0

## Release status

`v1.0.0` is the first complete stable release of the `lagrangian` skill package.

## What changed from v0.9.5

- Added complete release manifest.
- Added installation and usage documentation.
- Added quality gate checklist.
- Added security and contribution guidance.
- Added JSON schemas for failure outputs, eval scenarios, and skill metadata.
- Added release validator script.
- Added golden-test index and expanded test governance.
- Added reproducibility notes and regression placeholders.

## What is intentionally not claimed

This release does not claim a newly measured benchmark score beyond the historical v0.9.x summary. `v1.0.0` is a packaging, governance, reproducibility, and stability release. Fresh benchmark numbers should be generated by running the eval suite in the target host environment.

## Compatibility

- Skill-only use: copy `lagrangian/`.
- Full engineering use: keep the entire package and run validation scripts.
